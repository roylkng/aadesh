# Docs Directory Guide

This directory contains implementation guidance, status, runbooks, design notes, and organized specs.

Read first:
- `ARCHITECTURE_STATUS.md`
- `DOCS_MAP.md`
- `specs/README.md`

## Active Docs

- `ARCHITECTURE_STATUS.md`: active/deferred/archive truth source.
- `IMPLEMENTATION_PLAN.md`: phased execution plan for active Aadesh scope.
- `WEDGE_V0_CODING_COGNITIVE_CONTINUITY.md`: continuity wedge constraints.
- `MEMORY_CONTRACT_VNEXT.md`: memory semantics and lifecycle contract (design-only).
- `POLICY_STATE_DECISION_NOTE.md`: policy-state now-vs-later decision.
- `EVALUATION_PERSISTENCE_DESIGN.md`: eval summary persistence model.
- `COMPARISON_BENCHMARK.md`: repeatable comparison protocol for Aadesh vs adjacent memory systems.
- `COMPETITOR_TESTING_NOTES.md`: notes on Hermes/OpenMemory testing patterns and Aadesh benchmark implications.
- `DESIGN_LAB_BOUNDARY.md`: Aadesh vs Design Lab boundary.
- `WEDGE_V0_RUNBOOK.md`: continuity runbook.
- `CONNECTOR_INTEGRATION_V0.md`: host connector strategy.
- `SUPERVISORY_LAYER_V1.md`: supervisory evolution note.
- `DOCS_MAP.md`: task-to-doc navigation.
- `CODEBASE_MAP.md`: code traversal map.
- `REPO_ORGANIZATION.md`: placement and hygiene rules.

## Specs

- `specs/active/`: canonical specs for the current implementation cut.
- `specs/deferred/`: long-horizon architecture specs retained as references.
- `specs/README.md`: active/deferred spec inventory.

## Deferred / Historical Docs In This Directory

- `WEDGE_V0_EMAIL_DRAFT_AND_SEND.md`: deferred legacy wedge brief.
- `QUICKSTART.md` and `DEMO_RUNBOOK.md`: runtime demo/bring-up docs, not product-scope authority.

Scope status is controlled by `ARCHITECTURE_STATUS.md`, not by file age or filename.
