# Docs Directory Guide

This directory contains implementation process and navigation documents.

- `IMPLEMENTATION_PLAN.md`: milestone sequencing and acceptance criteria.
- `WEDGE_V0_EMAIL_DRAFT_AND_SEND.md`: v0 product scope lock.
- `REPO_ORGANIZATION.md`: repository structure and placement rules.

Canonical behavior specs remain in the repository root.
